# Mini Notlar

Mini Notlar, HTML, CSS ve JavaScript ile gelistirilen basit bir not alma uygulamasidir.

## Hedef

Bu proje, sifirdan uygulama gelistirmeyi ogrenmek icin hazirlaniyor.

## Ozellikler

- Not yazma alani
- Not listesi
- Not sayaci

Sonraki asamalarda not ekleme, silme, kaydetme ve arama ozellikleri eklenecek.

## Dosyalar

- `index.html`: Sayfa iskeleti
- `style.css`: Tasarim
- `script.js`: JavaScript kodlari
